    Enum: FoodTypeEnum

    Primary food type classification. Grounded in FoodOn ontology (OBO Foundry). Each value maps to valid storage_requirement values via vm-storage-* rules.

    URI: inkind_knowledge_repo:FoodTypeEnum

    Permissible Values

    Value Meaning Description
    bread_bakery None Bread, rolls, pastries, cakes, and other baked goods
    fruit_vegetables None Fresh fruit, vegetables, and herbs
    meat_fish None Fresh or frozen meat, poultry, sausage, fish, and seafood
    dairy_eggs None Milk, cheese, yoghurt, and eggs
    dry_goods None Non-perishable dry staples: pasta, rice, flour, cereals, pulses
    canned_goods None Factory-sealed tins and cans
    beverages None Bottled or packaged drinks (non-alcoholic)
    confectionery_sweets None Chocolate, sweets, candy, and desserts
    ready_meals None Prepared meals — ambient (shelf-stable), refrigerated, or frozen
    baby_food None Commercially prepared solid baby food (purées, jars, pouches)
    condiments None Sauces, spreads, oils, vinegars, and seasoning products
    other None Food items not fitting above categories
