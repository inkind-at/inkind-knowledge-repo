    Enum: BeddingTextilesSubcategoryEnum

    Bedding and household textiles subcategories. Aligned with COICOP 05.2. is_winter_suitable is meaningful for the first five subcategories; suppressed by the fragment compiler for the last three.

    URI: inkind_knowledge_repo:BeddingTextilesSubcategoryEnum

    Permissible Values

    duvets_quilts None Duvets, quilts, continental quilts

    bedsheets None Fitted sheets, flat sheets, pillowcases, duvet covers
    towels None Bath, hand, face, beach towels
    curtains_blinds None Curtains, net curtains, roller blinds
    tablecloths_napkins None Tablecloths, placemats, cloth napkins
